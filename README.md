# 💼 Gerador de Orçamento Freelancer

Ferramenta web para geração de orçamentos profissionais para projetos de desenvolvimento web e design. Desenvolvida por [victory_dev](https://victorydev.vercel.app).

## ✨ Funcionalidades

- Seleção de tipo de projeto com valores base pré-definidos
- Extras configuráveis (SEO, WhatsApp, CMS, Analytics, Automações, UI/UX)
- Multiplicador de urgência (normal, urgente, super urgente)
- Campo de desconto percentual
- Cálculo de parcelamento automático
- Geração de PDF para impressão diretamente no navegador
- Layout responsivo para mobile e desktop

## 🛠 Stack

- HTML5 semântico
- CSS3 puro (variáveis, grid, flexbox, responsivo)
- JavaScript vanilla (sem dependências externas)

## 🚀 Como usar

1. Clone o repositório
```bash
git clone https://github.com/victorylesson/orcamento-freelancer.git
cd orcamento-freelancer
```

2. Abra o `index.html` no navegador (sem necessidade de servidor)

Ou acesse a versão online em: **[victorydev.vercel.app](https://victorydev.vercel.app)**

## 📁 Estrutura

```
orcamento-freelancer/
├── index.html     # Estrutura e formulário
├── style.css      # Estilos e identidade visual
├── script.js      # Lógica de cálculo e geração de PDF
└── README.md
```
